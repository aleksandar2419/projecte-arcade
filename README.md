# Projecte Arcade

## Descripció

Aquesta aplicació és una màquina àrcade feta en Python que funciona
per terminal. Permet jugar a dos jocs: Pedra, Paper, Tisora contra un
robot, en partides de diverses rondes (el primer a 3 victòries o al
millor de 5), i Endevinar el Número, on cal descobrir un número secret
entre 1 i 100 amb l'ajuda de pistes.

Està dividit en tres fitxers `main.py` conté el menú
principal i el bucle de l'aplicació, `jocs.py` la lògica dels jocs i
`robot.py` l'oponent de la màquina.
